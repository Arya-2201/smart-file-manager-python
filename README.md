# Smart File Manager

A desktop file manager built with Python and Tkinter.

## Features

- Recursive folder scanning
- Live file search
- Sort files by name and size
- Duplicate file detection using SHA-256
- Storage analytics dashboard
- Desktop GUI with Tkinter

## Technologies

- Python 3
- Tkinter
- pathlib
- hashlib
- collections

## Run

```bash
python gui.py
```

## Project Structure

- `gui.py` – User interface
- `scanner.py` – Recursive file scanner
- `search.py` – Search functionality
- `sorter.py` – Sorting algorithms
- `duplicate.py` – Duplicate detection
- `analytics.py` – Storage statistics
